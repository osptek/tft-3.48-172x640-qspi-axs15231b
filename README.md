## 产品简介

OSPTEK **3.48 寸 172×640 TFT** 是一款 **QSPI** 接口彩色显示模组，驱动芯片为 **AXS15231B**。细长分辨率适合条形 HMI、侧边状态条与紧凑信息面板等场景。

规格标识（仓库名）：`3.48-tft-172x640-qspi-axs15231b`

电气与外形细节以 `docs/` 中产品规格书为准。

## 规格参数

| 项目 | 规格 |
| ---- | ---- |
| 尺寸 | 3.48 英寸 |
| 类型 | TFT（彩色） |
| 分辨率 | 172×640 |
| 接口 | QSPI |
| 驱动 IC | AXS15231B |
